# 執筆ガイド（コンテンツの書き方）

このサイトのコンテンツはすべて `data/*.js` にあります。各ファイルは普通の `<script>` として読み込まれ、
`window.LEARN`（`data/_registry.js` で定義）に登録します。書いたら必ず検証スクリプトを通してください。

```sh
node tools/check.mjs            # data/ 以下を全部検査
node tools/check.mjs politics   # 1 科目だけ（politics-1.js と politics-2.js）
node tools/check.mjs politics-2 # 1 ファイルだけ
```

---

## 1. 読者と文体

- **読者**: 高校の社会科をほぼ忘れた社会人。スマホで少しずつ読む。
- **レベル**: 高校教科書レベル。「知らないと恥ずかしい」「ニュースを理解するのに要る」ものを優先。受験の細かすぎる暗記事項（マイナーな人名・年号）は削る。
- **文体**: 本文は「だ・である」調。短い文で、具体例を必ず添える。「なぜそうなったか」「今とどうつながるか」を一言でも入れる。
- **正確さ最優先**: 年号・人数・条文番号・統計は確かなものだけ書く。統計は「約」「2020年代半ば時点」などを付け、変わりやすい数字（順位・人口）は丸める。自信がない細部は書かない。
- 政治的に意見が分かれる論点は、両論を並べて事実として書く（どちらかに肩入れしない）。

## 2. 科目ファイルの形

1 科目は前半・後半の 2 ファイルに分けています（`data/politics-1.js` と `data/politics-2.js` など）。
`LEARN.subject()` は同じ科目 ID で何度呼んでも読み込み順に連結されます。

```js
LEARN.subject('politics', [
  {
    id: 'democracy',                 // 英小文字とハイフン。科目内で一意（下の目次表の ID を使う）
    title: '民主政治の基本原理',        // 講のタイトル（全角 20 字以内が目安）
    lead: '国家権力をどう縛るか――…',   // 1 文のリード（60 字前後）。[[ ]] 可
    points: [                          // この講の要点。ちょうど 3 つ（各 60 字以内）
      'ホッブズ・ロック・ルソーの[[社会契約説]]が…',
      '…',
      '…'
    ],
    body: `
## 見出し
本文の段落。1 段落は 1 行で書く。

## 次の見出し
…
`,
    terms: [                           // 重要用語 8〜14 語
      ['社会契約説', '国家は、自然状態にある人々が互いに契約を結んでつくったものだとする考え方。'],
      …
    ],
    quiz: [                            // 確認問題 5〜6 問。4 択
      { q: '問題文', c: ['選択肢A', '選択肢B', '選択肢C', '選択肢D'], a: 2, e: '解説（なぜそれが正解か、ほかがなぜ違うか）' },
      …
    ]
  },
  …
]);
```

### 分量の目安（1 講あたり）

| 項目 | 目安 |
|---|---|
| body | 全角 2,500〜4,500 字。見出し（`##`）4〜7 個 |
| terms | 8〜14 語。説明は 1〜2 文（40〜90 字） |
| quiz | 5〜6 問。正解位置 `a` は 0〜3 にばらけさせる |

## 3. 本文（body）の書式

行頭の記号で種類が決まります（各行は前後の空白が削られてから解釈されます）。

| 書き方 | 表示 |
|---|---|
| `## 見出し` | 節の見出し（目次ボタンにもなる） |
| `### 小見出し` | 小見出し |
| 空行 | 段落の区切り。**段落は 1 行で書く**（連続する行は区切りなしで連結される） |
| `- 項目` | 箇条書き |
| `1. 項目` | 番号付きリスト（順序に意味があるときだけ） |
| `\| 見出し \| 見出し \|` | 表。1 行目が見出し行。区切り行 `\|---\|---\|` はあってもなくてもよい |
| `> 文` | 「ポイント」の囲み |
| `!> 文` | 「ここで間違えやすい」の囲み（よくある誤解・ひっかけ） |
| `?> 文` | 「豆知識」の囲み（話のネタになる雑学） |
| `n> 文` | 「ニュースで見るとき」の囲み（ニュースのこの言葉はこういう意味、など） |
| `{{fig:図ID\|キャプション}}` | 図（下の図一覧から） |
| `{{steps:段階1\|段階2\|段階3}}` | 手順・流れの図（STEP 1, 2, 3…） |

同じ記号の囲みが連続する行は 1 つの囲みにまとまります（行ごとに改行）。

### インライン

| 書き方 | 意味 |
|---|---|
| `[[語句]]` | **重要語**（オレンジ表示。赤シートで隠れる）。1 講に 15〜40 個程度。答えになる語句に付ける |
| `**語句**` | 強調（マーカー） |
| `{漢字\|かんじ}` | ふりがな（難読の人名・用語だけ）。表や `{{steps:}}` の中でも使える |
| `[文字](#learn.科目ID.講ID)` | 別の講へのリンク（下の目次表の ID のみ） |

### 禁止事項

- body の中でバッククォート（`` ` ``）と `${` を使わない（テンプレート文字列が壊れる）。
- HTML タグを書かない（エスケープされて表示される）。
- 段落の行頭を `- ` `|` `>` `#` `{{` で始めない（別の書式として解釈される）。
- `[[ ]]` の中に `**` や別の `[[ ]]` を入れない。

### 使える図（`{{fig:ID|キャプション}}`）

| ID | 内容 | 想定する講 |
|---|---|---|
| `sanken` | 三権分立（国会・内閣・裁判所と矢印） | 政治 |
| `supply-demand` | 需要曲線と供給曲線、均衡価格 | 経済 |
| `business-cycle` | 景気循環（好況・後退・不況・回復） | 経済 |
| `circular-flow` | 家計・企業・政府の経済循環 | 経済 |
| `maslow` | マズローの欲求階層 | 倫理 |
| `dialectic` | ヘーゲルの弁証法（正・反・合） | 倫理 |
| `pop-pyramid` | 人口ピラミッドの 3 つの型 | 地理 |
| `river-landforms` | 河川がつくる地形（V字谷→扇状地→氾濫原→三角州） | 地理 |
| `pressure-belts` | 大気大循環と気圧帯・風系 | 地理 |

## 4. 用語（terms）

- 本文で `[[ ]]` を付けた語の中から、特に大事なものを選ぶ。
- 説明に用語そのものを含めない（自動クイズで「〇〇」に伏せられるが、読みにくくなる）。
- 同じ科目の中で同じ用語を 2 回登録しない。
- 用語と説明だけで意味が通じるように書く（暗記カードとして単体で出る）。

## 5. 確認問題（quiz）

- 4 択。選択肢は同じカテゴリで紛らわしいものにする（人物なら人物、年代なら年代）。
- 「すべて正しい」「どれでもない」は使わない。
- `e`（解説）は 1〜3 文。なぜ正解か＋誤答の選択肢が何なのかも短く。
- 本文を読めば解ける範囲から出す。
- 問題文・選択肢・解説にも `[[ ]]` 以外のインライン書式は使える（`**強調**` など）。`[[ ]]` は問題文では使わない。

## 6. 年表（`data/timeline.js`）

```js
LEARN.events([
  { y: -3000, l: '前3000頃', t: 'メソポタミアで都市国家が成立', d: 'シュメール人が楔形文字を使い…', s: 'history' },
  { y: 1789, t: 'フランス革命が始まる', d: '…', s: 'history' },
  { y: 1868, t: '明治維新', s: 'japan' },
]);
```

- `y`: 並べ替え用の数値（紀元前は負の数）。`l`: 表示用ラベル（省略時は `y` をそのまま表示。紀元前は「前○○」）。
- `t`: 出来事（40 字以内）。`d`: 補足 1 文（任意）。
- `s`: `history` / `politics` / `economics` / `ethics` / `geography` / `japan`（そのころの日本。世界史と並べて時代感をつかむため）。
- `[[ ]]` は使わない。`**強調**` は可。

## 7. 人物（`data/people.js`）

```js
LEARN.persons([
  { n: 'ソクラテス', y: '前469頃〜前399', s: 'ethics', k: '[[無知の知]]。「ただ生きるのではなく、よく生きる」ことを説いた', d: '問答法で…', w: '著作なし（弟子プラトンが記録）' },
]);
```

- `n` 名前、`y` 生没年、`s` 科目 ID、`k` 一言で何をした人か（`[[ ]]` 可。暗記カードの裏面の主役）、`d` 補足 1〜2 文、`w` 主著・代表作（任意）。
