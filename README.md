# おとなの社会科／理科／常識／雑学

高校の「政治・経済」「倫理」「地理」「世界史」と「物理」「化学」「生物」「地学」から、大人として**知っておくべき基礎**をまとめた個人用の学習サイトです。マナー・冠婚葬祭などの「常識」と、「なぜ？」に答える練習をする「雑学」もあります。画面左上のブランド名をタップしてコースを切り替えます。
スマホで少しずつ読んで、解いて、覚えることを想定しています。ビルド不要の静的サイトなので、ファイルを置くだけで動きます。

## できること

| 画面 | 内容 |
|---|---|
| **学ぶ** | 社会 5 科目 66 講、理科 4 科目 52 講、常識 3 科目 24 講。雑学は一問一答 5 科目。各講は「要点 3 つ → 本文（表・図・囲み）→ 重要用語 → 確認問題」の順 |
| **赤シート** | 本文のオレンジの語句を赤シートで隠し、タップでめくって確認（講ページと辞典で使える） |
| **4択クイズ** | 各講の確認問題＋用語から自動で作る問題。科目・問題数・「まだ解いてない」「苦手優先」を選べる |
| **暗記カード** | 用語カード・人物カード。「覚えた／まだ」で 1日→3日→1週間→16日→35日と間隔をあけて再出題（ライトナー方式） |
| **どっちが先？** | 年表から 2 つの出来事を出して、先に起きたほうを当てるゲーム |
| **年表** | 世界史を軸に、政治・経済・思想・地理・科学史の出来事と「そのころの日本」を 1 本の時間軸に |
| **辞典** | 全用語と人物の一覧。絞り込み検索つき |
| **検索** | 講の本文・用語・人物・年表をまとめて検索 |
| **ごほうび** | 経験値・レベル・称号、宝石、実績メダル（銅・銀・金）、科目の勲章、デイリーミッション、宝石で交換する着せ替え |
| **学習記録** | 12 週間の学習カレンダー、科目別の読了率・正答率・定着した用語数 |

記録（読了・解答・カード）はブラウザの localStorage に保存されます。別の端末に移すときは「設定 → 記録の引っ越し」で書き出し・読み込みができます。

## 開き方

- **公開版**: https://yyrtjhgjj-byte.github.io/learnings/
  `main` に push すると GitHub Actions（`.github/workflows/pages.yml`）がコンテンツを検証してから GitHub Pages に公開します（Settings → Pages → Source は「GitHub Actions」）。スマホの「ホーム画面に追加」でアプリのように使え、一度開けばオフラインでも読めます。1 ファイル版は https://yyrtjhgjj-byte.github.io/learnings/otona-shakai.html 。
- **手元で開く**: `index.html` をブラウザで開くだけでも動きます（オフライン機能は無効）。
- **1 ファイル版**: `node tools/build.mjs` で `dist/otona-shakai.html` ができます。CSS・JS・データを全部埋め込んだ単体の HTML なので、この 1 ファイルだけ持ち運べます。

## 構成

```
index.html              画面の骨組み（データとアプリの読み込み）
assets/css/style.css    見た目（ライト／ダーク両対応）
assets/js/app.js        アプリ本体（ルーター・各画面・クイズ・カード・記録）
data/_registry.js       データの受け皿（window.LEARN）
data/<科目>-1.js, -2.js 各科目の講（前半・後半）
data/timeline*.js       年表（社会・科学史）
data/people*.js         人物（社会・科学者）
data/diagrams.js        図解（SVG。tools/gen-diagrams.py で生成）
docs/CONTENT_GUIDE.md   執筆ガイド（書式・分量・講 ID 一覧）
tools/check.mjs         コンテンツの検証
tools/build.mjs         1 ファイル版の生成
sw.js                   オフライン対応
```

## コンテンツを足す・直す

1. [`docs/CONTENT_GUIDE.md`](docs/CONTENT_GUIDE.md) の書式で `data/*.js` を編集する。
   本文は簡易マークアップ（`## 見出し`、`[[重要語]]`、`> ポイント`、`| 表 |` など）。
2. `node tools/check.mjs` で検証する（書式ミス・選択肢の重複・正解番号の範囲外・リンク切れなどを検出）。
3. 新しいファイルを足したら `index.html` と `sw.js` の一覧にも 1 行足す。

統計や制度の数字は執筆時点（2020 年代半ば）のものです。
